## About me

I'm a Software Engineer at **EPAM Systems**, building reusable web components for enterprise applications. Before that I worked at **NEORIS**, **Fisapay** and **Emberalab**, across frontend, backend and client support.

- 🧩 **What I do best:** component-based frontends with Lit, React and Angular, in strict TypeScript.
- 🧪 **How I work:** tests I'd want to inherit — unit tests with Mocha, Sinon, Jest and Vitest; end-to-end with Cucumber/BDD, Cypress and Playwright.
- 🔧 **Beyond the frontend:** REST APIs in Java (Spring Boot) and Python (FastAPI), SQL tuning, a Go prototype, and native apps in Kotlin.
- 📚 **Currently learning:** GraphQL in depth, Go and design systems.
